Get started

Run it locally
1

Clone the repository

git clone https://github.com/LarsBoecking/Statistical_Learning_TUM.git && cd Statistical_Learning_TUM
2

Create an environment and install dependencies

python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
3

Run the notebooks from their own folder

Lecture figures are generated by the notebooks in 02_lectures_code/; the exercises live in 03_exercises_code/. Launch Jupyter from a notebook's directory so the relative paths to configs/ and data/ resolve.
